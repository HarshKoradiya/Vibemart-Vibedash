# Vibemart & Vibedash

Vibemart is a One stop Shopping Website for the Users with Vast Collection of Products,Fast Delivery Service and Easy Payments.

Vibedash is a Comprehensive Admin Dashboard for Business Owners Where they can Run And Manage Their Business Without much Effort and Grow Their Business.


Technologies Used : 
MongoDB : For Managing Data of the website,
Express-js : For Making Good-quality Apis,
React-js : For An Intutiative Ui,
Node-js : For Stronng Backend Services.
